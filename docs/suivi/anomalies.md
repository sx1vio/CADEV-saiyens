# Registre des anomalies

Registre vivant des bugs et des écarts (code, CI, outillage, processus) rencontrés pendant le développement. Il permet à toute l'équipe de voir ce qui est ouvert, qui s'en occupe et **comment** chaque problème a été résolu.

> **Mise à jour en temps réel** : une anomalie trouvée s'ajoute ici (et en issue avec le modèle « bug » si elle demande du travail) ; une anomalie corrigée est mise à jour dans la PR qui la corrige. Dernière mise à jour : **8 octobre 2026**.

## Comment remplir

| Champ              | Contenu                                                                                                                            |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| ID                 | `BUG-NNN`, séquentiel, jamais réutilisé                                                                                            |
| Gravité            | **Critique** (démo ou données en danger) · **Majeure** (fonction ou garde-fou cassé) · **Mineure** (contournable) · **Cosmétique** |
| Statut             | Ouvert · En cours · Corrigé · Rejeté · Reporté                                                                                     |
| Correctif appliqué | Cause racine **et** solution, pas seulement « corrigé »                                                                            |
| Référence          | Commit, branche, PR ou issue                                                                                                       |

Modèle à copier :

```markdown
### BUG-NNN

| Champ                  | Valeur                  |
| ---------------------- | ----------------------- |
| Titre                  |                         |
| Description            | Observé : … Attendu : … |
| Étapes de reproduction | 1. …                    |
| Gravité                |                         |
| Statut                 | Ouvert                  |
| Détection              | AAAA-MM-JJ, par …       |
| Correction             | —                       |
| Correctif appliqué     | —                       |
| Référence              |                         |
```

## Anomalies corrigées

### BUG-010

| Champ                  | Valeur                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Titre                  | Import GitHub (PR #99) : requête refusée par GitHub (422)                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Description            | Observé : `GithubHttpClient.listOwnedRepos` appelle `/user/repos?type=owner&visibility=public`. La vraie API GitHub répond `422 If you specify visibility or affiliation, you cannot specify type`. Attendu : la liste des dépôts publics dont l'utilisateur est propriétaire. Invisible en test et en local, car le faux client GitHub (`AUTH_FAKE_PROVIDER=true`) et le `fetch` simulé ne valident pas les paramètres.                                                                      |
| Étapes de reproduction | `gh api "/user/repos?type=owner&visibility=public"` → 422 ; `gh api "/user/repos?affiliation=owner&visibility=public"` → 200                                                                                                                                                                                                                                                                                                                                                                  |
| Gravité                | Critique : en production, l'import du profil (PR1, Jalon 1) échoue à chaque connexion, puis est réessayé 3 fois                                                                                                                                                                                                                                                                                                                                                                               |
| Statut                 | Corrigé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Détection              | 2026-10-08, par Joachim (relecture de `modules/github`)                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Correction             | —                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Correctif appliqué     | Cause : GitHub refuse `type` combiné à `visibility` (422) ; le faux client des tests ne pouvait pas le révéler. Solution : `affiliation=owner&visibility=public`, test qui interdit `type` avec `visibility`, client vérifié contre la vraie API (7 dépôts listés, compétences calculées). En plus : jeton révoqué (401) non réessayé, quota épuisé réessayé avec `Retry-After`. Leçon retenue : tout adaptateur d'API externe est essayé au moins une fois contre la vraie API avant fusion. |
| Référence              | Commit `c6c1508`, fusionné dans #99 (`1d1d241`)                                                                                                                                                                                                                                                                                                                                                                                                                                               |

### BUG-011

| Champ              | Valeur                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Titre              | Supprimer la branche d'une PR fusionnée ferme les PR empilées dessus                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Description        | Observé : après la fusion de #98 puis de #101 avec suppression de leur branche, GitHub a **fermé** #99 et #104 (dont la base était cette branche) au lieu de les rebasculer vers `main`. Une PR fermée dont la branche a été réécrite ne peut plus être rouverte.                                                                                                                                                                                                                                                                  |
| Gravité            | Majeure : relectures et discussions perdues si la PR doit être recréée                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Statut             | Corrigé                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Correctif appliqué | #99 et #104 rouvertes (branche de base recréée temporairement, réouverture, base changée vers `main`, branche supprimée). **Règle pour les PR empilées** : (1) fusionner la PR du bas **sans** supprimer sa branche ; (2) rebaser la PR suivante sur `main` (`git rebase --onto origin/main <ancienne base>`), la pousser avec `--force-with-lease` et changer sa base vers `main` ; (3) seulement ensuite, supprimer la branche fusionnée. Ne pas activer « Automatically delete head branches » tant que l'équipe empile des PR. |
| Responsable        | Caleb                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Référence          | PR #99, PR #104, [workflow Git](../equipe/workflow-git.md)                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
